# EBS Customisations

See @../../.claude/skills/oracle-ebs/SKILL.md for full EBS standards.

## Quick Reference
- Object prefix:  [XXBU]_
- Modules:        AR, AP, GL, PO, INV, OM, HR, FA
- Reports:        reports/ folder (.rdf files)
- Interfaces:     interfaces/ or conversions/ folder
- OAF:            extensions/ folder
- Forms:          forms/ folder (.fmb source only - no .fmx)
- Workflows:      workflows/ folder (.wft files)
